This repository contains the data modeling and analysis scripts for the Subscription Revenue Attribution & LTV Modeling project. The primary objective was to resolve misallocated marketing spend by accurately attributing revenue to specific acquisition channels over time. The architecture relies on dbt-core to transform raw event data from Google Cloud BigQuery into a denormalized revenue mart. This mart handles multi-touch attribution logic, specifically implementing a time-decay weighting model to distribute credit across user touchpoints. The source data includes GA4 events and CRM subscription records, correlated to match ad spend with downstream revenue events.

The Python scripts within the `src` directory handle the statistical validation of the attribution model using pandas. These scripts calculate cohort retention curves and project dynamic Lifetime Value (LTV) metrics. The resulting data feeds into a Power BI dashboard, where DAX measures are used to visualize ROAS improvements and identify channel inefficiencies. The project successfully identified a 12% over-allocation to low-performing channels and improved ROAS reporting accuracy by 25%. Setup requires a GCP project with BigQuery enabled and dbt-core installed. The `requirements.txt` file lists the necessary Python dependencies for local analysis and data validation. The repository structure separates the dbt models from the exploratory Python analysis, ensuring that the transformation logic remains version-controlled and testable against the BigQuery data warehouse.
