This repository contains the core logic for the Legal Case Outcome Prediction and Document Search tool, developed for an enterprise legal client in 2024. The system addresses the inefficiency of manual precedent research by automating the extraction of key entities from case documents and predicting outcomes based on historical data.

The architecture consists of three main components. First, a data ingestion layer using `sqlalchemy` to interface with the firm's PostgreSQL database, where case metadata, parties, and outcomes are stored. Second, a text processing pipeline using `nltk` and `pandas` to clean and vectorize case summaries, extracting significant legal terms and themes. Third, a recommendation and prediction engine using `scikit-learn` to calculate semantic similarity scores between new cases and historical precedents, and to train a classifier for outcome prediction.

Setup requires Python 3.9+ and a local PostgreSQL instance. Install dependencies via `pip install -r requirements.txt`. Configure the database connection string in `config.py` (not included in repo for security). Run `pipeline.py` to execute the full workflow: data extraction, text processing, similarity calculation, and model training. The tool has demonstrated a 30% reduction in case research time and a 15% improvement in outcome prediction accuracy compared to manual methods. Data privacy is maintained by processing documents locally and not retaining raw text in the vector database.
