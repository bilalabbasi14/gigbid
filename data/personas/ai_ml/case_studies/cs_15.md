# Image Quality Assurance Pipeline — 2019 | Media (Individual Client)

- **Project ID:** p15 | **Duration:** 4 weeks  
- **Role:** CV Engineer (AI/ML Engineer – NLP, RAG, CV, MLOps) – Priya Raman  
- **Tech Stack:** Python 3.8, OpenCV 4.2, Docker 19.03, Git 2.23, Bash 5.0  
- **Repo:** `github.com/priyaa/image-quality-pipeline` (private)  

## Sprint 0 – Kickoff & Requirements (Day 1‑3)  
- Met client (solo photographer) via Zoom; captured use‑cases: detect *blur* (kernel‑based variance < 150) and *over‑exposure* (mean pixel > 230).  
- Defined KPI: **≥ 90 % detection accuracy** & **≥ 80 % reduction** in manual review time.  
- Scoped deliverable: single‑file CLI (`iqa.py`) wrapped in a Docker image, runnable on macOS/Linux workstations.  

## Sprint 1 – Prototype & Baselines (Day 4‑7)  
- Collected 2 800 sample JPEGs (1 400 sharp, 1 400 blurry; 1 200 properly exposed, 1 200 over‑exposed).  
- Implemented baseline sharpness metric using **Laplacian variance**; baseline exposure check via **histogram mean**.  
- Quick script achieved **84 %** blur detection, **78 %** exposure detection (≈ 81 % combined).  

## Sprint 2 – Metric Refinement (Day 8‑12)  
- Switched blur metric to **Tenengrad** (Sobel gradient magnitude) → +6 % recall.  
- Added **dynamic thresholding** per ISO/EV metadata (extracted via `exifread`).  
- Updated exposure metric to **percentile‑based clipping** (top 5 % pixel > 250) → +5 % precision.  
- New combined accuracy: **92 %** (precision = 0.91, recall = 0.93).  

## Sprint 3 – Dockerization & CLI (Day 13‑17)  
- Wrote Dockerfile: `FROM python:3.8-slim`; installed `opencv-python==4.2.0.32`; set entrypoint to `python iqa.py`.  
- Image size: **118 MB** (≈ 30 % smaller than previous monolithic builds).  
- Implemented batch mode: `docker run --rm -v $(pwd)/photos:/data iqapipeline:latest /data`.  
- Added `--json` flag for structured output (file‑path, blur_score, exposure_score, verdict).  

## Sprint 4 – Testing, CI/CD, Documentation (Day 18‑24)  
- Created **pytest** suite (48 tests) covering edge cases: extreme ISO, RAW → JPEG conversion, corrupted files.  
- Integrated GitHub Actions: lint (flake8 3.8), unit tests, Docker build push to private ECR.  
- Measured runtime: **0.42 s/image** on Intel i7‑9700K (single‑core).  
- Produced README.md with usage examples, threshold tuning guide, and performance chart.  

## Sprint 5 – Deployment & Client Handoff (Day 25‑28)  
- Delivered Docker image (`registry.example.com/iqapipeline:1.0.0`).  
- Conducted remote walkthrough; client processed 5 000 images in **≈ 35 min** vs. **≈ 240 min** manual review (≈ 85 % time saved).  
- Signed off on SLA: **≤ 2 % false‑negative** rate for blur, **≤ 3 %** for exposure.  

## Post‑Release (Day 29‑30) – Retrospective & Future Work  
- **What went well:** rapid metric iteration, lightweight container, clear CLI contract.  
- **Challenges:** limited metadata consistency; resolved via fallback histogram analysis.  
- **Next steps (client‑requested):** add **color‑cast detection** (using CIELAB delta‑E) and optional **GPU acceleration** via `opencv-contrib-python`.
