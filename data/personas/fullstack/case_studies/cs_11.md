# Micro‑lending Platform API – 2023 Fintech Startup  

When the founders approached me in early 2023, they had a clear vision: a fast, secure backend that could handle everything from loan applications to payouts, but they were struggling with latency in credit‑score checks and a fragile payout flow. As the Backend Lead, I spent the next 13 weeks turning that vision into a production‑grade API that now processes millions of dollars of loans every quarter.

We started by picking Node.js with TypeScript because the team already used React on the front end and wanted type safety across the stack. Express became the natural choice for the HTTP layer – it’s lightweight, well‑documented, and integrates cleanly with the middleware we needed for authentication and request validation. For data persistence we went with PostgreSQL, using TypeORM to map our domain models (Applicant, Loan, Repayment) to tables. The decision to use an ORM paid off quickly; we could write complex queries like “find all loans with overdue repayments older than 30 days” in a single repository method, and TypeORM handled the underlying joins without us writing raw SQL.

Credit‑score lookups proved to be the biggest performance bottleneck. Each application required a call to an external scoring service, and the latency added up to more than a minute per request. To solve this, I introduced ioredis as a caching layer. We cache the score for a borrower for 24 hours, which reduced the average application latency from 48 hours (including manual review) to under 6 hours once the API was live. The Redis cache runs in a Docker container alongside the API, orchestrated with Docker Compose for local development and later deployed to a Kubernetes pod in production.

Payouts were handled through Stripe Connect. The Stripe library gave us a straightforward way to create connected accounts for borrowers and to initiate disbursements directly to their bank accounts. We wrapped the Stripe calls in a service layer that retries on transient network errors and logs every transaction for audit purposes. This design satisfied the compliance team’s requirement for full traceability.

Testing was a non‑negotiable part of the process. Using Jest we wrote unit tests for every service and integration tests that hit a temporary PostgreSQL instance spun up with Docker. Over 85 % code coverage gave the client confidence to ship early.

After launch, the platform processed $3 M in loans within the first four months, and the average approval time dropped from 48 hours to just 6 hours—a tenfold improvement. The repo (microlending-api) remains open for internal audits, and the Docker images are rebuilt nightly to incorporate security patches. This project reinforced my belief that a well‑chosen stack, disciplined type safety, and strategic caching can turn a high‑risk fintech concept into a reliable, scalable service.
