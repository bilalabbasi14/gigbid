# Property Listings Portal – Phase 1 (2022, Real Estate)

- **Project ID:** p03  
- **Duration:** 10 weeks (Jan 10 – Mar 20 2022)  
- **Role:** Lead Front‑end Engineer (Full‑stack responsibilities delegated to back‑end teammate)  

## Sprint 1 – Setup & Architecture (Week 1‑2)  
- Initialized monorepo with `npm init -y`; added `next@13.2`, `typescript@5.0`, `tailwindcss@3.3`.  
- Dockerfile created: `node:18-alpine` base, multi‑stage build → final image ~120 MB.  
- Set up CI pipeline on GitHub Actions: `lint`, `type‑check`, `build`, `docker push`.  
- Chose **Prisma** over Sequelize for type‑safe DB access; generated schema from existing PostgreSQL dump (v13).  
- Decided on **SSR** for all listing pages to satisfy SEO requirement; disabled static generation for admin routes.  

## Sprint 2 – Core Data Layer (Week 3)  
- `prisma generate` → client types exported to TypeScript (`@prisma/client`).  
- Implemented pagination via cursor‑based queries (`take: 20`, `skip: cursor`).  
- Added index on `listings.price` and `listings.location` → query latency dropped from 210 ms to 68 ms (PostgreSQL EXPLAIN).  
- Wrote migration `20220301_add_listing_status.sql` to introduce `status ENUM('active','pending','sold')`.  

## Sprint 3 – SEO & Routing (Week 4)  
- Integrated `next-seo` with default title template `"${title} | Regional Realty"`.  
- Configured `robots.txt` and sitemap generation (`next-sitemap`).  
- Implemented dynamic meta tags per listing (`og:image`, `description`) using server‑side props.  
- Benchmarked Lighthouse SEO score: **92 → 98** after meta optimization.  

## Sprint 4 – UI / Forms (Week 5‑6)  
- Adopted `tailwindcss` JIT mode; created reusable component library (`Button`, `Card`, `Badge`).  
- Built responsive grid (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`) for listing cards.  
- Integrated `react-hook-form` for contact inquiry modal; validation schema via `zod` (v3).  
- Form submission POST → `/api/inquiry`; added reCAPTCHA v3 token verification.  

## Sprint 5 – Performance & Caching (Week 7)  
- Enabled `Cache-Control: stale-while-revalidate` on SSR pages via `next.config.js`.  
- Added Redis (Docker container) for query result caching; hit rate ~73 % on listing pages.  
- Reduced Time‑to‑First‑Byte (TTFB) from 420 ms to 185 ms (NGINX proxy in front of Node).  

## Sprint 6 – Testing & QA (Week 8)  
- Unit tests with Jest (`@testing-library/react`) – 85 % coverage on UI components.  
- End‑to‑end tests with Cypress; critical path (search → inquiry) passed 12/12 scenarios.  
- Conducted accessibility audit (axe); fixed 4 WCAG 2.1 AA violations (color contrast, ARIA labels).  

## Sprint 7 – Deployment & Handoff (Week 9‑10)  
- Docker Compose production stack: `next-app`, `postgres`, `redis`, `nginx`.  
- Deployed to AWS ECS Fargate; auto‑scaling policy: CPU > 70 % → add 1 task (max 4).  
- Created runbook: environment variables, backup schedule (daily pg_dump to S3), roll‑back steps.  

## Outcome Metrics (Post‑Launch, 2 months)  
- Lead generation ↑ **30 %** (tracked via HubSpot form submissions).  
- Target keywords (“regional rentals”, “city sales”) reached **Page 1** on Google SERP.  
- Average session duration: **3 min 12 s** (up from 2 min 05 s).
