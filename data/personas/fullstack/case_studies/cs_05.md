# Property Listings Portal – Phase 3 (Analytics) | 2023 | Real Estate  

When the agency approached us in early 2023, they were struggling to turn the flood of interaction data from their property listings into actionable insights. Their existing portal, built on React and Next.js, displayed listings beautifully, but there was no systematic way to understand which agents were performing best, which listings were attracting the most views, or how pricing tweaks were influencing sales. As the Backend Lead, I was tasked with designing and delivering an analytics layer that could ingest high‑velocity events, summarize them efficiently, and surface the results in intuitive dashboards for the agents.

We began by mapping the event flow: every page view, click, and inquiry generated a lightweight JSON payload from the front‑end. To keep the ingestion latency low, we routed these events through an Express gateway that immediately pushed them into Redis using the **ioredis** client. Redis served as a fast, in‑memory buffer where we could increment counters and maintain sliding windows without hitting the database on every hit. After a short aggregation window (typically five minutes), a Node.js worker process would read the buffered data, compute daily and weekly summaries, and write the results into PostgreSQL via the **pg** library. This hybrid approach gave us the best of both worlds—real‑time responsiveness from Redis and durable, relational analytics stored in Postgres.

The core of the service was a GraphQL API built with **apollo-server-express**. Exposing the analytics data through GraphQL allowed the existing React components to request exactly the fields they needed for each dashboard widget, reducing over‑fetching and keeping the front‑end snappy. I defined types for agents, listings, and aggregated metrics, and implemented resolvers that pulled pre‑computed summaries from Postgres while still being able to fall back to Redis for the most recent minute‑level data when necessary.

On the visualization side, the agency’s front‑end team integrated **Chart.js** widgets into the portal’s “Agent Dashboard” page. We provided endpoint documentation and sample queries, and I worked closely with the UI developers to fine‑tune the chart configurations—using line charts for traffic trends, bar charts for agent performance rankings, and doughnut charts for price‑segment distributions. The dashboards were containerized with Docker, matching the portal’s existing deployment pipeline, which made the rollout seamless across their Kubernetes cluster.

The six‑week sprint concluded on schedule, and the analytics service went live in late March 2023. Within the first month, 90 % of the agency’s staff were regularly logging into the new dashboards. The data‑driven pricing recommendations derived from our summaries contributed to a 4 % uplift in average sale price across the portfolio—a direct, measurable impact on the bottom line. The repo, **realestate-portal-analytics**, remains open for internal extensions, and the architecture we built continues to scale as the agency adds new event types and expands to additional markets.
