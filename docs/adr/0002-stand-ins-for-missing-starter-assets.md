# ADR 0002: Stand-ins for starter-kit assets not yet provided

**Status:** accepted · **Date:** 2026-11-11

## Context
The starter kit received contained the repository skeleton, tiny samples and an illustrative
policy pack. The GigSim simulator, the three persona corpora, the instructor policy pack, the
historical job stream and the dev evaluation set were not included. Most of the system depends on
them, so waiting would block the project.

## Decision
Build replaceable stand-ins, each behind a swap point, and label them clearly:

| Asset | Stand-in | Swap point |
|---|---|---|
| `gigsim/` | Student-built FastAPI simulator (`GIGSIM_ORIGIN=student-built` in its README) with jobs, clients with hidden preferences, Connects, proposals, messages, rate limits, random 5xx and LLM-simulated client decisions | `mcp_servers/marketplace/adapters/gigsim.py` talks to a small REST contract; when the instructor's GigSim arrives the adapter is re-pointed and `gigsim/.lock.sha256` freezes the folder so CI fails on any change |
| Persona corpora | Generated by committed scripts (`data/scripts/`) from real Upwork job categories (Kaggle) plus synthetic case studies, code and labelled proposals; marked SYNTHETIC in `docs/DATA_CARD.md` | Replace `data/personas/`, run `make ingest`, rerun `make eval` |
| Policy pack | Starter rules extended, versioned (`policy_version`) and mirrored in `data/policy_pack/policy.yaml` | Replace file, bump version in `agent/config.yaml` |
| Job stream | Kaggle Upwork postings filtered to the three personas; 1,500 historical for pricing, a pool drip-fed as "live", with planted duplicates, scams and injection posts | Scout reads from whichever GigSim is configured |
| Dev eval set | Gold labels from rules + LLM, manually spot-checked | Replace `evals/datasets/`; runners unchanged |

## Consequences
- All results reported before the instructor's assets arrive are explicitly labelled as measured
  on the stand-in data.
- The real assets drop in with no code changes beyond the adapter mapping and a re-index.
