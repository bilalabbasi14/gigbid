This project was built by one student with an AI coding assistant (Claude Code, Anthropic) used
as a pair programmer. I remain responsible for every line, every design decision and every
reported number. This file is updated at each milestone.

## How the assistant was used
- Drafting boilerplate (configuration loaders, Makefile targets, CI workflows, Dockerfiles).
- Proposing designs that I then reviewed against the assignment brief and adjusted.
- Writing first drafts of tests and documentation, which I edited.
- Explaining library APIs (LangGraph, MCP SDK, pgvector) when versions differed from my notes.

It did **not** produce evaluation numbers: every figure in the README and report is generated by
scripts in `evals/runners/` and committed under `evals/results/`.
